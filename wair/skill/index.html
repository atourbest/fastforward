Set up your AI coach

Your coach lives in one project in the AI assistant you already use. Set it up once, in about three minutes. After that, every new chat in the project is your coach, and it knows the whole course.

It asks one question at a time, notices patterns in your answers, and helps you draft your story in your own words.

Step 2: create your project

  2. Open the project’s instructions and paste in the project instructions.
  3. Add the coaching file to the project’s files.
  4. Start a new chat inside the project and type Start Day 1

  2. Paste the project instructions into the project’s instructions.
  3. Add the coaching file to the project’s files.
  4. Start a new chat in the project and type Start Day 1

Gemini

  1. Create a new Gem called Who Am I Really?
  2. Paste the project instructions into the Gem’s instructions.
  3. Add the coaching file to the Gem’s knowledge.
  4. Start a chat with the Gem and type Start Day 1

Using your coach

Open a new chat in your project for each session, then type:

  • Start Day 1 to Start Day 5 to work through the course, one day at a time
  • Start my origin story for the bonus chapter
  • Or just ask for help with your story in your own words

How your coach remembers

If your AI has memory turned on, your coach saves a short summary of your answers at the end of each day, and picks up where you left off in the next chat. You can ask it to forget at any time.

If memory is off (some work accounts do this), your coach gives you a Brand File instead: a short summary of your answers. Save it somewhere safe and paste it in next time.

On Day 5, either way, you get your finished story and introduction to keep.

A note on privacy

You’ll be talking about your values, your strengths and some of the moments that shaped you. Share only what you’re comfortable with. If you use AI at work, think about using a personal account for this instead.
